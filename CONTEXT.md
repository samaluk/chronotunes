# Domain glossary

## Catalog

A collection of tracks available for play. A catalog contains factual track metadata and
references to external playback services. It does not contain audio recordings.

## Demo catalog

A small, independently selected catalog distributed with ChronoTunes so a developer can try
the game without importing a full catalog.

## Catalog source

An external collection, such as a Spotify playlist, from which ChronoTunes can derive a
catalog. A catalog source may be general or tied to a particular publisher or game edition.

## Catalog importer

A tool that derives a ChronoTunes catalog from a catalog source. The general importer accepts
ordinary Spotify playlists. Optional source-specific adapters may understand how a publisher
organizes playlists by country or game edition.
