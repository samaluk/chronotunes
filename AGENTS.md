# AGENTS.md

ChronoTunes is a browser-based multiplayer music timeline game (Hitster clone) with YouTube audio.

## Essentials
- Package manager: pnpm
- Stack: Next.js 16 App Router + TypeScript, Convex backend
- Type generation: `pnpm next:typegen`, `pnpm convex:typegen`
- Do not skip tests or ignore Biome issues; ask for explicit agreement first if either is proposed.
